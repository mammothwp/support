# Translations

Put `mammothwp-support-<locale>.mo` (and `.po`) files here. The package loads
`languages/mammothwp-support-<locale>.mo` from the copy that won the election,
using the text domain `mammothwp-support`. Generate the template with
`wp i18n make-pot . languages/mammothwp-support.pot --domain=mammothwp-support`.
